# Local processing and site access

Label.ai checks visible media on approved public pages. A host grant lets the extension run on the selected site. Local settings further limit analysis to approved origins. Browsing pages show only the positive badge. The extension has no account, telemetry endpoint, analysis service or database.

An image or video already displayed by the page can supply readable pixels. The browser may prevent pixel access to cross-origin media, protected streams and other restricted sources. In these cases the route abstains. The original file is required for signature verification. Forming a new JPEG from visible pixels would destroy the original credential. Original-data routes accept bounded embedded bytes or tightly limited public sources. For a same-origin image with a recognized content digest in its address, the extension can request that existing published file with credentials omitted, redirects rejected and the referrer suppressed. Its body is checked locally against the digest. A separate same-origin JPEG route uses only the browser's HTTP cache and verifies full-resolution displayed pixel equality before examining a public cached original. The publisher may see a qualifying download. There is no upload, URL lookup, analytics request, remote trust lookup or cloud fallback.

Model, verification software and trusted roots ship in the install package. Build-time downloads and explicit developer test fixture downloads are different from browsing. Instances and in-flight decisions are short-lived. The extension stores the enabled setting, consent version and user-approved origins locally. Model errors, private/sensitive paths, permission loss and unsupported sources produce no visible verdict. URL rules and password-form detection cannot recognize every private page on a public host. Enable individual public sites deliberately and pause on shared or authenticated services.

Pause local analysis, remove a site, or clear local data in the extension's site-access page. Browser settings can also withdraw the host permission or remove the extension. The package does not record browsing histories, export media, or collect user reports in the background.

# On-device build plan

1. Record architectural changes, preserve all 64 requirement IDs, and establish strict privacy and evaluation tests.
2. Build portable Chromium and Safari WXT targets, local settings and active-document discovery. Connect Svelte/SMUI badges to actual decisions. Bind every job to the current source and grant.
3. Integrate real local image inference and verification of embedded C2PA credentials in eligible original bytes. Prove tested routes with known-origin examples. Only validated routes can issue production labels.
4. Evaluate temporal video inference on a disjoint full-video holdout. Exercise source changes, playback preservation and insufficient coverage.
5. Package both extension targets, validate Chromium-family installations and native Safari, run the privacy/network suite, and report support on public sites. Record remaining legal, hardware and statistical gates.

The primary agent owns integration, evaluation, documentation, browser testing and packaging. Dedicated agents own the extension, local inference, and provenance packages. No service endpoints are part of the runtime. See PROGRESS.md and RELEASE_GATES.md for actual status.
